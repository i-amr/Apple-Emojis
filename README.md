# Apple Emojis

A complete, organized collection of Apple emojis provided in both **160x160** and **72x72** pixel resolutions. 

## 📁 Repository Structure

* `/160` - High-resolution (160x160px) emoji assets, ideal for retina displays, stickers, and large UI elements.
* `/72` - Standard-resolution (72x72px) emoji assets, optimized for fast web loading, inline text, and compact interfaces.
* `/unofficial` - Handcrafted additions designed to match Apple's native aesthetic, including:
  * 🔤 Custom alphabet letters
  * ♂️♀️ Custom Male/Female gender signs
